# ASO - Ejercicios y tareas

Repositorio personal con los ejercicios y tareas de la asignatura de ASO (Administración de Sistemas Operativos) correspondiente a 2º de ASIR en el IES de Curtis.

Este proyecto sirve como cuaderno de trabajo donde se van recopilando prácticas, entregas y actividades realizadas durante el curso.

## 📚 Contenido del repositorio

La estructura del repositorio está organizada por bloques temáticos:

- `Ejercicio 2` — ejercicios prácticos del segundo bloque.
- `Ejercicio 3` — actividades y material del tercer ejercicio.
- `Tarea 1` — primera tarea de la asignatura.
- `Tarea 2` — segunda tarea de la asignatura.
- `Tarea 3` — tercera tarea de la asignatura.
- `Tarea 04` — entrega adicional / tarea 4.
- `Otros` — recursos, apuntes o archivos complementarios.

## 🎯 Objetivo

El objetivo principal de este repositorio es:

- guardar y organizar el trabajo realizado en clase,
- mantener un historial claro de las prácticas,
- facilitar la revisión y entrega de tareas,
- servir como referencia para futuras actividades.

## 🛠️ Uso

Puedes navegar por cada carpeta para consultar el contenido de cada ejercicio o tarea. El repositorio está pensado para ir creciendo con nuevas entregas y materiales.

## 🧾 Estado

El proyecto se encuentra en desarrollo y se actualiza conforme se realizan nuevos ejercicios y tareas.
